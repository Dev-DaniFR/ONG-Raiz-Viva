🌿 ONG Raiz Viva

Projeto de uma plataforma web para a ONG Raiz Viva, desenvolvido como parte de um curso de Front-End, aplicando boas práticas de HTML5, CSS3 e JavaScript.

## 🛠️ Tecnologias:
```
• HTML5: Estrutura Semântica;
• CSS3: Flexbox, Media Queries, Variáveis (Design System); 
• JavaScript (DOM, SPA básico, eventos).
```

## ✨ Especificações 
```
📌 Fundamentos e Estrutura: 
• Estrutura Semântica utilizando index.html, projetos.html e cadastro.html;
• Formulário de cadastro utilizando tipos de input HTML5 específicos (e-mail, date, tel);
• Validação nativa com uso de atributos required, pattern e title;
• Arquivos validados pelo W3C Validator.

🎨 Estilização e Design System:
• Variáveis CSS para paleta de cores, tipografia e espaçamentos;
• Layout responsivo com breakpoints e Flexbox;
• Navegação com menu principal e menu hambúrguer;
• Componentes responsivos: cards, botões, formulários e tags de feedback.

⚡Dinâmica e Interatividade:
• SPA Básica manipulando o DOM;
• Templates JS para renderizar conteúdo dinâmico(simulação de cards de projetos);
• Lógica do menu hambúrguer;
• Alternância entre Modo Claro e Modo Escuro.
```

## 💻 Como Executar o Projeto Localmente
1. Clone este repositório:  
   `git clone https://github.com/Dev-DaniFR/ONG-Raiz-Viva.git`
2. Acesse a pasta do projeto:  
   `cd ONG-Raiz-Viva`
3. Abra o projeto no VS Code:  
   `code .`  
   (ou abra o arquivo **index.html** diretamente no navegador)
4. Recomenda-se usar a extensão **Live Server** no VS Code para visualizar o projeto.
